# speak4write_bot

Бот для Telegram, который переводит голосовые сообщения, аудио и видео в текст с помощью модели `whisper-large-v3` от Groq API.

## Установка

Убедитесь, что у вас установлен Docker и Docker Compose.

Просто скопируйте и вставьте эту команду в терминал вашего сервера:

```bash
curl -sSL https://raw.githubusercontent.com/ВАШ_НИК/speak4write_bot/main/install.sh | bash
```

*(Замените ВАШ_НИК на ваш username на GitHub)*

## Особенности
- Поддержка голосовых, аудио, видео и "кружочков".
- Автоматическая ротация API-ключей Groq для обхода лимитов.
- Развертывание в Docker одной командой.
