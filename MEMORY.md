### Qwen3.5-9B-Claude model evaluation
- **Конфигурация ПК:** E5 2680 v3 (8 ядер), 32 ГБ ОЗУ, Nitro RX 590 (8 ГБ VRAM), два NVMe‑диска (512 ГБ + 256 ГБ) + два SATA SSD (480 ГБ + 512 ГБ).
- **Совместимость:** Модель `Qwen3.5-9B-Claude-4.6-HighIQ-THINKING-HERETIC-UNCENSORED` требует ≈18‑20 ГБ VRAM; доступно лишь частичная квантизация (Q4_KS ~5‑6 ГБ, Q5_KS ~6‑7 ГБ). Запуск возможен при ограничениях:
  - Скорость будет умеренной (десятки токенов/сек).
  - Качество хорошее, но без полного функционала auf современном GPU.
- **Рекомендация:** Лучше использовать квантизированную версию Q4_KS/Q5_KS через `llama.cpp` или `ollama`.

С учётом ограничений, тестовый запуск не выполнен, но проект занесён в мемории для будущего контроля.
