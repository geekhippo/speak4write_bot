# 2026-06-21 — News bot overhaul & OpenModel config

## News bot code optimisation and fixes

### AI module (`ai.py`)
- **Geo-filter fix**: removed `"урал"`, `"уральськ"`, `"лесной"` from `OTHER_REGIONS` — they were falsely rejecting Sverdlovsk/Ural news.
- **Cleaned up `EKAT_KEYWORDS`**: removed overly broad words (`девять`, `канал`, `культура`), removed duplicates (`лесной`, `невьянск`).
- **Async rewrite**: replaced blocking `requests` with `httpx.AsyncClient` to avoid event loop blockage.
- **Removed dead code**: `_ai_check_location`, `select_best_news`, `_pick_best_from_source`, `are_duplicates`.

### Bot module (`bot.py`)
- **Forbidden error handling**: when user blocks bot, they're auto-unsubscribed instead of spamming errors.
- **Removed `__import__` hack**: replaced with proper `from database import get_latest_from_source`.
- **Cleaned duplicate imports**.
- **Critical fix**: Replaced `asyncio.get_event_loop().create_task(_news_loop())` with `asyncio.create_task(_news_loop())` inside `post_init` — Python 3.12 deprecated the old pattern, causing the background task to run only once (lost to wrong event loop).

### Database (`database.py`)
- **Removed dead functions**: `find_similar_news`, `get_next_batch_by_cursor`, `get_last_sent_id`, `set_last_sent_id`.
- **Moved `import re`** to module level.
- **Added `get_latest_from_source()`** — clean replacement for the `__import__` workaround.

### Parser (`parser.py`)
- **Removed `ItsMyCityParser`** — dead code (defined but never registered).

### Cleanup
- **Deleted** `config.py` (empty) and `sources.json` (unused).
- **Dockerfile**: removed dead `ENV WORK_*` variables.
- **requirements.txt**: added `httpx`.

## OpenModel provider setup
- **Provider `openmodel`** added to `openclaw.json` with `api: "anthropic-messages"`, `timeoutSeconds: 180`.
- **Model `openmodel/deepseek-v4-flash`** registered and working.
- Key insight: OpenModel requires Anthropic-style `/v1/messages` endpoint, not OpenAI style.

## Key decisions
- Unsubscribe blocked users instead of retrying forever.
- Move task creation into `post_init` where event loop is running — avoids Python 3.12 deprecation trap.
