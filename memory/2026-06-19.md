### Что делали

#### 1. Исправление геофильтра
- **Проблема:** Бот присылал новости из других регионов (Пермь, Иркутск, Москва и т.д.)
- **Причина:** AI-фильтр был слишком мягким, полагался на AI даже когда ключевые слова отсутствовали
- **Решение:** Жёсткий фильтр по ключевым словам в `news_bot/ai.py`:
  - Список `EKAT_KEYWORDS` — слова Екатеринбурга/Свердловской области
  - Список `OTHER_REGIONS` — слова других регионов/стран
  - Логика: если есть слова других регионов и нет слов Екатеринбурга — отсекать; если нет ничего — отсекать

#### 2. Выбор по одной новости из каждого источника
- **Проблема:** AI выбирал несколько новостей от одного источника
- **Решение:** Функция `select_best_news()` группирует по источнику, из каждого берёт одну лучшую через AI

#### 3. Меню команд Telegram
- **Проблема:** Не было кнопки Menu в интерфейсе Telegram
- **Решение:** `BotCommand` + `set_my_commands` через `post_init` хук
- Команды: `/start`, `/news`, `/stats`, `/menu`, `/stop`

#### 4. Единый визуальный формат новостей
- **Проблема:** Новости выглядели по-разному (у одних превью ссылки, у других нет)
- **Решение:** Функция `_format_news_text()` — единый шаблон для всех новостей, `disable_web_page_preview=True`

#### 5. Планировщик — ежечасный сбор
- **Проблема:** `run_once` + `run_repeating` конфликтовали, бот не присылал новости каждый час
- **Решение:** Заменён на `asyncio.create_task(_news_loop())` — фоновый цикл с `asyncio.sleep(3600)`
- Первый сбор через 3 секунды после старта, потом каждый час

#### 6. Немедленный сбор при запуске
- Бот сразу собирает новости при старте (через 3 секунды)
- Команда `/news` всегда доступна, собирает свежие новости по запросу
