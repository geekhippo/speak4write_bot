### Meshtastic проект (в разработке)
- **Концепция:** Бот для Meshtastic mesh-сети на базе Raspberry Pi
- **Серверная нода:** Raspberry Pi 1 + LoRa модуль (868MHz)
- **Портативная нода:** Heltec V3 (уже есть у пользователя)
- **Функции:** погода каждые 12 часов, курс валют, ping-ответчик
- **Текущий статус:** Обсуждено, пока не реализовано
- **Варианты подключения LoRa к Raspberry Pi:**
  1. USB-UART адаптер с LoRa (DX-LR32, ~$12)
  2. Готовое Meshtastic-устройство с USB (Heltec V2/V3, T-Beam, $10-20)
  3. Ra-02 (SX1276, 868MHz) подключение по SPI к GPIO (~$2-3)
- **Частота:** 868MHz (Европа)

### CyberDeck проект (в разработке)
- **Концепция:** Информационная панель на ESP32 + экран
- **Железо пользователя:**
  - ESP32 DevKit
  - Heltec V3 (LoRa + экран)
  - Raspberry Pi 1
  - Набор с AliExpress (артикул 5113908245): ESP32, макетная плата, провода, кнопки, светодиоды, OLED дисплей, потенциометр
  - Estardyn 2.25" цветной LCD модуль ST7789 (76×284, SPI) — куплен отдельно
- **Вариант реализации:** MicroPythonOS (lvgl_micropython) — портирование на ESP32 DevKit + ST7789
- **Альтернатива:** Чистый MicroPython (код уже написан в `/root/.openclaw/workspace/cyberdeck/main.py`)
- **Текущий статус:** Обсуждено, пользователь хочет попробовать MicroPythonOS
